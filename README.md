# AI Chat (ریلوی)

چت وب/موبایل برای هر API سازگار با OpenAI (`/v1/models` و `/v1/chat/completions`).
متن، عکس، فایل (txt/md/json/csv/pdf)، صدا (mp3/wav)، ورودی صوتی، استریم، تنظیمات، خروجی گرفتن، خوندن پاسخ با صدا، نصب روی گوشی (PWA).

## دیپلوی
1. این پوشه رو توی یه ریپوی GitHub جدید آپلود کن.
2. توی Railway: New Project > Deploy from GitHub repo > ریپو رو انتخاب کن.
3. (اختیاری) توی Variables مقدار `API_BASE_URL` و `API_KEY` رو بذار.
4. توی Settings > Networking > Generate Domain بزن تا لینک بگیری.

Railway خودش `PORT` رو میده و Node رو تشخیص میده. نیاز به تنظیم Build یا Start Command نیست (`npm start`).

## نکته
کلیدها و تنظیمات کاربر فقط توی localStorage مرورگر ذخیره میشن. سرور فقط درخواست رو به API مقصد پروکسی میکنه.

## امنیت (حتماً بخون)
- `APP_PASSWORD`: اگه ست کنی، هر درخواست به `/api/*` باید رمز رو داشته باشه. اگه `API_KEY` داری، این رو هم ست کن، وگرنه هرکی آدرس سایتو داشته باشه از کلیدت استفاده می‌کنه.
- SSRF: سرور به آدرس‌های داخلی (localhost، 10.x، 192.168.x، 169.254.x و ...) وصل نمیشه. اگه مدل لوکال داری `ALLOW_PRIVATE_UPSTREAM=1` بذار (روی Railway نذار).
- کلید API به‌صورت پیش‌فرض توی مرورگر نگه داشته میشه. اگه دستگاه مشترکه، تیک «کلید رو نگه دار» رو توی تنظیمات بردار؛ اون‌وقت کلید فقط تا بسته شدن مرورگر می‌مونه.

## امکانات
- System prompt، خلاقیت (temperature) و حداکثر توکن از تنظیمات قابل تغییره.
- چت‌ها و فایل‌ها توی IndexedDB ذخیره میشن (حجم بیشتر از localStorage). چت‌های قدیمی خودکار منتقل میشن.
- لاگ JSON ساده برای هر درخواست (بدون بدنه درخواست و بدون کلید).

## تست
```
npm test
```
تست سرور (احراز هویت، SSRF، path traversal، پروکسی و استریم) با `node --test` اجرا میشه. Node 18 یا بالاتر لازمه.

# AI Chat (ریلوی)

چت وب/موبایل برای هر API سازگار با OpenAI (`/v1/models` و `/v1/chat/completions`).
متن، عکس، فایل (txt/md/json/csv/pdf)، صدا (mp3/wav)، ورودی صوتی، استریم، تنظیمات، خروجی گرفتن، خوندن پاسخ با صدا، نصب روی گوشی (PWA).

## دیپلوی
1. این پوشه رو توی یه ریپوی GitHub جدید آپلود کن.
2. توی Railway: New Project > Deploy from GitHub repo > ریپو رو انتخاب کن.
3. (اختیاری) توی Variables مقدار `API_BASE_URL` و `API_KEY` رو بذار.
4. توی Settings > Networking > Generate Domain بزن تا لینک بگیری.

Railway خودش `PORT` رو میده و Node رو تشخیص میده. نیاز به تنظیم Build یا Start Command نیست (`npm start`).

## نکته
کلیدها و تنظیمات کاربر فقط توی localStorage مرورگر ذخیره میشن. سرور فقط درخواست رو به API مقصد پروکسی میکنه.

## امنیت (حتماً بخون)
- `APP_PASSWORD`: اگه ست کنی، هر درخواست به `/api/*` باید رمز رو داشته باشه. اگه `API_KEY` داری، این رو هم ست کن، وگرنه هرکی آدرس سایتو داشته باشه از کلیدت استفاده می‌کنه.
- SSRF: سرور به آدرس‌های داخلی (localhost، 10.x، 192.168.x، 169.254.x و ...) وصل نمیشه. اگه مدل لوکال داری `ALLOW_PRIVATE_UPSTREAM=1` بذار (روی Railway نذار).
- کلید API به‌صورت پیش‌فرض توی مرورگر نگه داشته میشه. اگه دستگاه مشترکه، تیک «کلید رو نگه دار» رو توی تنظیمات بردار؛ اون‌وقت کلید فقط تا بسته شدن مرورگر می‌مونه.

## امکانات
- System prompt، خلاقیت (temperature) و حداکثر توکن از تنظیمات قابل تغییره.
- چت‌ها و فایل‌ها توی IndexedDB ذخیره میشن (حجم بیشتر از localStorage). چت‌های قدیمی خودکار منتقل میشن.
- لاگ JSON ساده برای هر درخواست (بدون بدنه درخواست و بدون کلید).

## تست
```
npm test
```
تست سرور (احراز هویت، SSRF، path traversal، پروکسی و استریم) با `node --test` اجرا میشه. Node 18 یا بالاتر لازمه.

## امکانات جدید
- **محدودیت تاریخچه:** توی تنظیمات تعداد پیام‌های آخری که فرستاده میشن رو مشخص کن (۰ = همه).
- **Rate limit:** `RATE_LIMIT_PER_MIN` (پیش‌فرض ۶۰ درخواست در دقیقه برای هر IP).
- **همگام‌سازی:** یه کد (حداقل ۸ کاراکتر) توی تنظیمات روی همه دستگاه‌ها بذار. چت‌ها روی سرور توی `DATA_DIR` ذخیره میشن. روی Railway یه Volume وصل کن و `DATA_DIR` رو روی مسیر Volume بذار، وگرنه با هر دیپلوی پاک میشن. دادهٔ همگام‌سازی به‌صورت JSON خام ذخیره میشه، پس کد رو مثل رمز نگه دار.
- **تداخل همگام‌سازی:** اگه یه چت روی دو دستگاه تغییر کرده باشه، نسخه‌ای که پیام بیشتری داره می‌مونه. حذف‌ها هم همگام میشن.
- **جستجو، تغییر اسم، حذف تکی، ویرایش پیام:** از سایدبار و زیر هر پیام کاربر.
- **جدول و کپی کد:** جدول markdown رندر میشه و هر بلاک کد دکمه کپی داره.
- **شمارنده توکن:** تخمین تعداد توکن‌های چت بالای صفحه نشون داده میشه.
- **خروجی و ورود پشتیبان:** توی تنظیمات > داده‌ها، همه چت‌ها به‌صورت JSON ذخیره یا وارد میشن (ورود فقط چت‌های جدید رو اضافه می‌کنه).

## قابلیت‌های پیشرفته
- **این چت:** هر چت پریست (برنامه‌نویس، مترجم، نویسنده، معلم)، دستور اختصاصی (System prompt) و مدل جدا می‌تونه داشته باشه. تنظیماتش توی بخش «این چت» تو تنظیمات.
- **پروژه‌ها:** دستورالعمل مشترک و فایل‌های متنی. فایل‌های بزرگ‌تر از ۶۰۰۰ کاراکتر تکه‌تکه میشن و فقط بخش‌های مرتبط با سوال فرستاده میشن (جستجوی کلیدواژه‌ای، بدون نیاز به API اضافه).
- **مقایسه مدل‌ها:** توی تنظیمات یه «مدل دوم» انتخاب کن. هر سوال به هر دو مدل میره و جواب‌ها با برچسب مدل کنار هم میان.
- **جستجوی وب:** با `BRAVE_API_KEY` فعال میشه. اگه تیک «جستجوی وب» زده باشه، نتایج قبل از جواب به مدل داده میشه و منابع زیر جواب نشون داده میشن.
- پروژه‌ها هم توی همگام‌سازی هستن.
- PDF هنوز متن‌شو استخراج نمی‌کنه: فقط فایل‌های متنی برای پروژه‌ها قبول میشن.
